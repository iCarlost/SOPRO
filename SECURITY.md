# Politica de Seguridad

## Reporte de vulnerabilidades

SOPRO utiliza **GitHub Private Vulnerability Reporting** para recibir reportes de vulnerabilidades de forma segura y confidencial.

Para reportar una vulnerabilidad:

1. Ve a la pestana **Security** del repositorio en GitHub.
2. Haz clic en **Report a vulnerability**.
3. Sigue el formulario para describir la vulnerabilidad.

No publiques vulnerabilidades en Issues publicos.

## Proceso de respuesta

1. El equipo recibira tu reporte de forma privada via GitHub.
2. Recibiras una confirmacion de recepcion.
3. El equipo evaluara la severidad y el impacto.
4. Se coordinara una fecha de divulgacion si aplica.
5. Se publicara un advisory una vez corregido el problema.

## Alcance

- La revision cubre el codigo fuente de SOPRO.
- Las dependencias de terceros se reportan segun sus propios procesos de seguridad.
- Los instaladores distribuidos via `SOPRO-Releases` estan incluidos en el alcance.

## Versiones soportadas

El soporte de seguridad se aplica a la **ultima version estable** publicada. No se garantiza correccion de vulnerabilidades en versiones anteriores.

## Divulgacion coordinada

SOPRO sigue el proceso de divulgacion coordinada de GitHub. Los detalles de la vulnerabilidad no se hacen publicos hasta que exista una correccion disponible o haya pasado un plazo razonable de notificacion.
